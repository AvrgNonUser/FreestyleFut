\# Freestyle Football



Proyecto de videojuego arcade de fútbol freestyle desarrollado en Unity como parte de un proyecto académico.



\## Descripción



\*\*Freestyle Football\*\* es un videojuego arcade enfocado en realizar dominadas y diferentes trucos con un balón de fútbol. El objetivo del juego será mantener el balón en el aire, conseguir combos y superar los récords obtenidos durante las partidas.



Actualmente, el proyecto se encuentra en su primera etapa de desarrollo e incluye una escena de entrenamiento diseñada como una cancha de fútbol freestyle.



\## Características actuales



\* Terreno diseñado en Unity.

\* Zona de entrenamiento de fútbol freestyle.

\* Cancha para realizar las actividades del juego.

\* Elementos decorativos y estructurales.

\* Iluminación de la escena.

\* Diferentes objetos creados mediante las herramientas de Unity.



\## Requisitos



\* Unity

\* Git

\* Windows



\## Cómo ejecutar el proyecto



1\. Clonar o descargar este repositorio.

2\. Abrir \*\*Unity Hub\*\*.

3\. Seleccionar \*\*Open Project\*\*.

4\. Seleccionar la carpeta principal del proyecto.

5\. Abrir la escena:



```text

Assets/Scenes/Escena\_Principal.unity

```



6\. Presionar el botón \*\*Play\*\* en Unity.



\## Navegación por la escena



Actualmente, la escena representa una zona de entrenamiento de fútbol freestyle.



La escena contiene una cancha ubicada en el área central y diferentes elementos decorativos distribuidos alrededor de ella.



Las mecánicas de movimiento del jugador, interacción con el balón y realización de dominadas serán implementadas durante las siguientes etapas del desarrollo.
